# Guitar Key Atlas

A one-page toolkit for guitar practice. Open `index.html` in a browser, or use the hosted version on GitHub Pages.

## What's in it

- **Jam station**: pick a key and a chord progression, press play, and solo over it with a matching scale lit up on the neck. Change the key, scale, strum pattern, drums or tempo while it plays. The notes of the chord that is sounding are ringed on the neck.
- **Your own progressions**: build one from the chords in the key, or tap in chords in the chord finder and jam with them.
- **Scales**: every scale for any key (major, minor, pentatonics, blues, all the modes, harmonic and melodic minor, Phrygian dominant), shown on the fretboard and played back one position at a time.
- **Chords, CAGED and voicings**: the seven chords of the key, the five CAGED shapes for each, and playable voicings for 17 chord types up the neck.
- **Drums and metronome**: rock, half-time, lofi swing, shuffle, funk and waltz beats that stay in time with the progression.
- **Practice**: exercises that update for the current key, including one-minute chord changes and an ear-training quiz.
- **Chord finder** (its own tab): tap where your fingers are to name the chord, see which keys it belongs to, and work out the key of a progression.
- **Tuner** (`tuner.html`, the tuning fork at the top right): listens through your microphone and shows how far off each string is, or plays reference tones to tune by ear. Standard, Drop D, half step down, Open G, Open D and DADGAD.

All sound is generated in the browser. There are no other files and nothing to install.

## Notes

The microphone tuner needs the page to be served over HTTPS (GitHub Pages does this) or opened from your own computer. Your browser asks for permission the first time.
