# Guitar Key Atlas

A one-page toolkit for guitar practice. Open `index.html` in a browser, or use the hosted version on GitHub Pages.

## What's in it

- **Tuner**: listens through your microphone and shows how far off each string is, or plays reference tones to tune by ear. Standard, Drop D, half step down, Open G, Open D and DADGAD.
- **Scales**: every scale for any key (major, minor, pentatonics, blues, all the modes, harmonic and melodic minor, Phrygian dominant), shown on a fretboard and played back one position at a time.
- **Chord finder**: tap where your fingers are to name the chord, see which keys it belongs to, and work out the key of a progression.
- **CAGED**: the five CAGED shapes for any chord in the key, with the pentatonic scale around each one.
- **Chords in the key and voicings**: the seven chords of the key with diagrams, plus playable voicings for 17 chord types up the neck.
- **Progressions**: common progressions in major and minor keys that play back with strumming or fingerpicking, with a scale to solo over each.
- **Drums and metronome**: rock, half-time, lofi swing, shuffle, funk and waltz beats that line up with the progressions.
- **Practice**: exercises that update for the current key, including one-minute chord changes and an ear-training quiz.

All sound is generated in the browser. There are no other files and nothing to install.

## Notes

The microphone tuner needs the page to be served over HTTPS (GitHub Pages does this) or opened from your own computer. Your browser asks for permission the first time.
